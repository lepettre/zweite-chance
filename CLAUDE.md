# Arbeitsregeln für dieses Repository

- **Nichts verschwindet ohne ausdrückliche, doppelte Bestätigung des Nutzers.** Das gilt für Daten, Angebote,
  Verlauf, Protokolle, Merklisten-Regeln, Dateien, Branches und Releases. Keine automatische Aufbewahrungsfrist,
  kein stilles Überschreiben, kein Löschen "zum Aufräumen". Entfernen nur mit zwei getrennten Bestätigungen,
  vorher prüfen, dass alles andernorts erhalten ist; wo möglich bleibt ein früherer Stand wiederherstellbar.
- Datenerhalt und Zuverlässigkeit gehen vor Geschwindigkeit; trotzdem schlank und schnell bauen.
- Öffentlich so wenig wie möglich: veröffentlichte Daten sind verschlüsselt, README bleibt neutral.
